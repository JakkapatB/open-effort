Fable 5.2 is now the model a stuck task moves up to past Opus, and a Main Flow set to Fable runs on it; a session you run on Fable 5.1 or Fable 5 keeps its own. Every model is named from its id, so Fable 5.2, Fable 5 and ids with a date or a platform prefix show their real names. The mod also learns from your own requests whether changing the effort keeps a model's prompt cache: one loss holds the effort on that model, two keeps in a row free one not yet measured, and the pane says which applies to your model and how much of the session's prompts the cache served. A model the task moved to that does not answer its first request is given up for the session, with a toast. Checks that run at the same time all count, a prompt reads nothing for rows you did not type, the flow file is read while Haiku reads the request, and after a reading that ran out of time the next prompts wait 5 seconds instead of 15 until Haiku answers again.
