A new version is now plain to see: the band shows a highlighted Update button that opens the pane, in place of the dot on ≡, and Reload once updated. The update card has more room, and the band and the card wrap on narrow screens. Sessions already open now learn of a new version by themselves, without pressing Check: each looks every 30 minutes at what the machine read, and GitHub is still read at most once a day per machine, so a release can take up to about a day to show.
