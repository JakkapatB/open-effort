open-effort now tells you when a new version is out. Once a day (switch it off in the pane) and whenever you press Check now, it reads the newest version number from GitHub; when one is out, the band's ≡ shows a dot and the pane opens with Update now, which runs Claude Code's own plugin update, then Reload now. Where the update cannot run, the pane gives the command.
